CRISLY - how to add your own photos
Replace the files in the images/ folder with real photos using the SAME file names:
headphones.jpg  backpack.jpg  mug.jpg  succulents.jpg  notebook.jpg  sneakers.jpg
Any 4:3 photo (for example 800 x 600 px) works best. Free sources: unsplash.com, pexels.com.
The images supplied are illustrated placeholders. favicon.svg / favicon.png are the browser-tab icon.
